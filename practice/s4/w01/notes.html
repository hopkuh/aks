Раздел 1. Подготовка технического задания.

1.1 Определение района работ, а также целей и задачи

1.1.1 Подключение публичной кадастровой карты

Объект аэрофотосъемки - территория площадного характера с заданными в техническом задании границами, для которых проектируется и выполняется аэрофотосъемка в рамках одного технического проекта.

Для определения границ объекта аэрофотосъемки в работе используются кадастровые номера земельных участков. Это связано с тем, что заказчику зачастую необходимо снять конкретный земельный участок для дальнейших работ (проектирования, согласования и т.п.). В некоторых случаях заказчик сразу выдает границы объекта съемки в виде векторных данных или набора закоординированных поворотных точек.

Кадастровый номер по структуре своей состоит из 4 составляющих: кадастрового номера округа, кадастрового номера района,кадастрового номера квартала и кадастрового номера земельного участка.

Для определения местоположения и адреса участка можно использовать специализированный портал Росреестра: https://nspd.gov.ru/map . В поиске указывается интересующий нас кадастровый номер. Для того, чтобы определить характеристики местности или рельефа можно подключить космический снимок в качестве подложки.

На данном портале имеется минимальный инструментарий для измерений, поэтому уже на данном этапе можно получить ориентировочную площадь снимаемого участка. Однако для удобства дальнейшей работы и приведения все к единой системе в работе будет использоваться настольная версия ГИС программы QGIS (Desktop). При ее отсутствии на рабочем ПК (или ноутбуке) следует скачать последнюю стабильную версию с официального сайта: www.qgis.org.

Рабочее пространство программы состоит из основного окна просмотра, панели инструментов и панели слоев (дополнительно могут быть открыты и другие панели, но в работе они использоваться не будут и их можно отключить).

Для подключения Публичной кадастровой карты возможно использование стороннего прокси сервера. Для этого необходимо просто добавить новый слой в разделе XYZ Tiles:

https://gext.ru/rosreestr_xyz/{z}/{x}/{y}.png

Для этого необходимо открыть Вид - Панели - Браузер. В появившейся панели найти XYZ Tiles, нажать правой кнопкой мыши и выбрать Создать соединение. В окне XYZ Connection в поле Имя указать ПКК или PKK, а в поле Адрес скопировать ссылку: https://gext.ru/rosreestr_xyz/{z}/{x}/{y}.png . После выполнения этих действий в списке слоев XYZ Tiles появится слой с указанным именем. Нажмите на него правой кнопкой и выберите Add Layer to Project.

Через подключение WMS:

https://pkk.rosreestr.ru/arcgis/services/PKK6/CadastreWMS/MapServer/WMSServer?

Более подробно ознакомиться с процессом загрузки данных Публичной кадастровой карты в QGIS можно по ссылке: https://terraingis.ru/kadastrovaja-karta-v-qgis.html

Для загрузки существующих в сети интернет карт нам потребуется установить дополнение. В панели “Модули” - “Управление и установка модулей…”. В появившемся окне в строке поиска напечатать QuickMapServices и установить найденный модуль (Install Plugin), как показано на рисунке 3:

Данный модуль позволяет загружать карты из сети интернет в формате набора изображений (“тайлов”), как это реализовано в большинстве онлайн карт. Данный способ называется сервисом веб-карт (Web Map Service - WMS). Чтобы можно было использовать популярные источники данных - следует изменить настройки модуля. Для этого в панели инструментов выбираем “Интернет” - “QuickMapServices” - “Настройки”. В появившемся окне открываем вкладку “Загрузить сервисы” и нажимаем “Получить дополнительные источники данных”. 1.1.2 Создание слоя в QGIS

Далее нам необходимо создать слой, в котором будут храниться границы нашего объекта. Создаем новый векторный слой: «Слой» - «Создать слой» - «Создать слой Shapefile». Во всплывшем окне указываем «Тип геометрии» - «Полигон» и задаем имя и путь файла. Во избежание ошибок программы рекомендуется использовать латиницу (например Zaokskiy_Border). Для более точных геометрических измерений необходимо работать в 6-ти градусной Российской СК. Для работы подойдет GSK-2011/Gauss-Kruger. Номер зоны определяется долготой нашего объекта: N =λ/6. Полученное число округляется до целого в сторону большего. Для Москвы это будет СК Pulkovo 1942/Gauss-Kruger N7(Теперь используем GSK 2011).

Созданный слой будет отображаться в окне слоев:

Чтобы создавать объекты внутри этого слоя необходимо сделать его редактируемым, нажав соответствующую кнопку в панели инструментов () или же нажав «Слой» - «Режим редактирования».

1.1.3 Границы объекта (Объект является кадастровым участком)

В случае, если объект работ является кадастровым участком или кадастровым кварталом то границы объекта будут совпадать с ними. Для отрисовки объекта необходимо выбрать инструмент создания Добавить полигон (Ctrl+.) и левой кнопкой мыши нажать на участок на карте, чтобы создать поворотную точку и отрисовать границы объекта по кадастровой границе. Для завершения создания объекта необходимо нажать правую кнопку мыши. После завершения создания полигона он будет залит цветом слоя. Чтобы выйти из режима создания полигонов выберите в панели инструментов режим навигации или выбора . Для удаления объектов выделите их при помощи инструмента выбора , а затем нажмите кнопку Delete. Для более подробной информации о создании и редактировании векторных объектов обратитесь к официальной документации:

https://docs.qgis.org/3.10/ru/docs/user_manual/working_with_vector/editing_geometry_attributes.html#digitizing-an-existing-layer

Чтобы не потерять свои данные в ходе работы - не забывайте производить сохранение. Важно понимать, что необходимо сохранять не только структуру и свойства отображения слоёв (Сохранить проект) , но и сами слои (Сохранить правки). Закончив создавать объекты выключите режим редактирования .

Вы можете изменить свойства визуализации в свойствах слоя(открывается по нажатию правой кнопкой мыши на слое) во вкладке “Стиль” можно указать цвет и размер линий, а также цвет и прозрачность заливки.
