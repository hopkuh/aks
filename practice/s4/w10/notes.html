3.2 Создание полетного задания для БВС

Создание полетного задания заключается в определении траектории полета БВС и точек фотографирования в пространстве. В простом случае это сводится к определению поворотных точек БВС в географической системе координат (WGS-84). Для решения этой задачи необходимо определить начальную точку маршрута, направление съемки, базисы и приращения координат соседних точек фотографирования. В работе будет использоваться модуль FlightPlanner для QGIS. Для установки модуля заходим в панель Модули - Управление и установка модулей... и в поисковой строке вводим “Flight Planner”, а затем нажимаем Install Plugin. В качестве исходных данных для проектирования полетного задания используются:

границы объекта фотографирования,

направление полета,

параметры камеры,

фотограмметрические параметры (перекрытия)

характеристика рельефа

После указания всех этих параметров модуль автоматически генерирует закоординированные точки фотографирования с отдельным слоем, отображающим захват местности снимками:

Для более наглядного отображения можно использовать полупрозрачную заливку. В таком случае заливка визуально позволяет определить зоны с перекрытиями:

После того, как модуль построит полетное задание, будут созданы 4 временных слоя, в одном из которых координаты точек фотографирования, в другом размеры снимка на местности, маршруты съемки и поворотные точки для навигации БВС. Их необходимо сохранить, так как модуль создает их во временный слой, который исчезнет при следующем запуске QGIS.

По построенному полетному заданию в QGIS необходимо проанализировать следующие параметры:1. Продольный(Bx) и поперечные(By) базисы из расчетов и базис в QGIS

2. Количество снимков

3. Количество маршрутов

4. Высота фотографирования по формуле и в Flight planner

Для большинства программ управления БВС есть ограничения в количестве точек, которые может использовать автопилот. Поэтому загрузить координаты всех точек фотографирования может быть затруднительным. В связи с этим следует создать отдельный файл с поворотными точками БВС (точками, где БВС будет изменять траекторию своего движения). Для этого можно продублировать слой с точками фотографирования и удалить все точки, кроме крайних в маршрутах. Полученные поворотные точки можно сохранить в формате CSV для загрузки в программу для пилотирования:

В данной таблице указывается название поворотной точки, координаты этой точки, высота точки, а также угловая ориентация камеры в процессе фотографирования.

Также на итоговой схеме должна отображаться точка взлета и посадки (или две точки, если точка взлета не совпадает с точкой посадки), координаты которой были определены ранее. Для отображения проектируемой траектории движения создается новый векторный слой (Линия) и объединяет все точки маршрута. Для отображения рекомендуется использовать тип слоя Стрелка:

В выводе обязательно сравнить продольный и поперечный базис, а также количество маршрутов и количество снимков. По результатам необходимо получить в QGIS каталог поворотных точек, которые в дальнейшем экспортировать в формат kml для импорта во Fly Litchi.
