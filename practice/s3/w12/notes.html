2.5.4.Ориентирование модели

Для ориентации модели используется инструмент «Модель» - «Преобразовать объект» - «Повернуть объект». Далее следует развернуть модель лицом относительно осей координат программы. Выбрать ракурс сверху можно в «Модель» - «Ракурс». При ракурсе «Спереди» объект должен смотреть на пользователя лицом.

Для более точного ориентирования модели рекомендуется использование опорных точек для задания плоскости. Для этого необходимо зайти во вкладку Привязка и создать три опорные точки, лежащие в плоскости основания объекта. Точки можно создавать непосредственно на модели. После установки точек следует указать их координаты.

Задать масштаб модели можно с использованием масштабных линеек. Для этого необходимо создать два маркера, желательно расположенные на противоположных краях объекта, нажав в окне просмотра модели правой кнопкой мыши в необходимом месте и выбрав инструмент создать маркер. Далее в окне привязки выделить оба маркера и нажав правую кнопку мыши создать масштабную линейку. У появившейся масштабной линейки задать расстояние в метрах.

Полученную в ходе работы трехмерную модель необходимо экспортировать в формате .obj с наложенной текстурой в формате .jpg. Для указания материалов на модели используется дополнительный файл формата mtl(Material Template Library). В результате в папке с объектом должны храниться три файла - Model.obj, Model.mtl, Model.jpg.

В отчет необходимо включить скриншоты траектории съемки (с отображением положения снимков) и модели, полученные с трех стандартных ракурсов: спереди, сбоку и сверху.
