1.3.2. Съемка тест объектов

После подготовки съемочного стенда необходимо произвести предварительную оценку возможностей съемочной системы.

Для этого необходимо сделать два кадра с расчетного расстояния D. Один, с расположенными мирами в плоскости фокусировки, для определения падения разрешающей способности по полю изображения.

Второй с мирами, расположенными вдоль оптической оси - для определения падения разрешающей способности из-за расфокусировки. Также вдоль оптической оси необходимо установить линейку, для определения расстояния, на котором расположены объекты. Схема расположения мир представлена на рисунке 9. При выполнении съемки обязательно выполнять фокусировку на миру, расположенную в центре кадра. Результатом съемки будут служить два кадра, по которым будут выполняться дальнейшие расчеты.
