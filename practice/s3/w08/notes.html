2.2.Фотограмметрическая калибровка съемочной системы

Для более достоверной фотограмметрической обработки изображений следует определить точные значения элементов внутреннего ориентирования камеры. К ним относятся фокусное расстояние, координаты главной точки снимка и параметры дисторсии. Дисторсия для кадровой камеры в большинстве случаев описывается с использованием аппроксимирующей модели Брауна, которая также используется и в Metashape. Предварительные значения элементов внутреннего ориентирования можно определить из характеристик камеры, однако для точного определения необходимо произвести калибровку съемочной системы.

Следующие параметры могут быть уточнены в процессе калибровки в программе Metashape:

f - фокусное расстояние (в пикселях).

cx, cy - координаты главной точки

b1, b2 - коэффициенты аффинитета (Affinity) и скоса (Skew, коэффициент неортогональности)

k1, k2, k3, k4 - коэффициенты радиальной дисторсии.

p1, p2 - коэффициенты тангенциальной дисторсии.

В нашем случае калибровка будет производиться при помощи дополнительного инструмента автоматической калибровки программы Metashape. Для этого следует получить фотографии калибровочного изображения в виде шахматной доски которое выводится на дисплей экрана (в случае с изогнутыми мониторами необходимо распечатать калибровочное изображение).

В главном меню в панели Инструменты, следует выбрать Объектив - Показать калибровочную таблицу.... При помощи колесика мыши скорректируйте появившееся на мониторе изображение таким образом, чтобы число клеток по каждой стороне калибровочной таблицы было не меньше 10.

Сфотографируйте калибровочную таблицу (при помощи объектива (выбранного фокусного расстояния) и камеры, которые используются при съемке предмета) слегка варьируя угол обзора. Для наилучшего результата расстояние до монитора должно соответствовать расстоянию до объекта при съемке. необходимо сделать минимум пять снимков под разными углами к плоскости калибровочного изображения.

Для выхода из окна отображения калибровочной таблицы и возвращения в окно программы нажмите кнопку Отмена или кликните левой клавишей мыши в любом месте. Загрузите полученные фотографии на компьютер

При съемке калибровочной таблицы:

• Удостоверьтесь, что фокусное расстояние неизменно для каждой серии снимков (в случае использования объектива с переменным фокусным расстоянием).

• Избегайте бликов. При необходимости отодвиньте источник света от монитора.

• Располагайте камеру таким образом, чтобы калибровочная таблица занимала все пространство снимка.

Для загрузки фотографий калибровочной таблицы в Metashape создайте новый блок, нажав кнопку Добавить блок на вкладке Проект. Выберите команду Добавить снимки... в меню Обработка. В появившемся диалоговом окне укажите путь к папке с фотографиями и выберите изображения для загрузки. Нажмите кнопку Открыть.

Для калибровки объектива выберите команду Инструменты - Объектив - Откалибровать объектив.... 2. В диалоговом окне Калибровка объектива выберите необходимые параметры калибровки и нажмите кнопку OK. Результаты калибровки будут отображаться на вкладке Уточненная диалогового окна Калибровка камеры..., доступного из меню Инструменты. Рассчитанные значения могут быть сохранены в файле, для этого необходимо нажать кнопку Сохранить и выбрать место на диске для записи файла. Сохранённые параметры калибровки могут быть в дальнейшем использованы в других блоках и/или проектах, содержащих снимки сделанные теми же камерой и объективом.

После того как параметры калибровки для объектива сохранены, можно приступать к обработке исходных данных по проекту в отдельном блоке. При этом внутри блока необходимо зайти в диалоговое окно Инструменты - Калибровка камеры.. и на вкладке Начальная загрузить сохраненный ранее файл калибровки и выбрать опцию Зафиксировать калибровку. Это позволит избежать пересчета данных калибровки на этапе выравнивании снимков.

Подробнее о фотограмметрической калибровке цифровых камер можно прочитать в учебнике Фотограмметрия (Михайлов А.П., Чибуничев А.Г.), глава 7 параграф 3.
