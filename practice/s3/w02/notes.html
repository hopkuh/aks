1.2 Выбор и обоснование объекта съемки для создания трехмерной модели.

1.2.1. Выбор объекта съемки

Для фотограмметрической съемки наиболее подходящими объектами являются предметы простой формы с отсутствием бликующих элементов. Следует учитывать основные элементы, которые не подлежат корректной фотограмметрической обработке:

объекты, размер которых меньше разрешающей способности фотоаппарата;

прозрачные, зеркальные элементы;

одноцветные элементы без текстурных особенностей.

подвижные элементы

В качестве объекта для обучения желательно использовать предмет изготовленный из дерева или камня с матовой текстурой.

Размер объекта должен быть обусловлен размерами имеющейся съемочной площадки и возможностями съемочной системы.

Прозрачные или зеркальные объекты не могут быть корректно зафиксированы на фотоизображении. В таком случае в ходе обработки будет получен неудовлетворительный результат. Пример представлен на рисунке 2:

1.2.2. Стенд для проведения фотосъемки

В качестве стенда для съемки рекомендуется использовать фотобокс (рисунок 3).

Основной задачей фотобокса является создание равномерно фона вокруг объекта. При отсутствии фотобокса необходимо обустроить место для съемки так, чтобы поле кадра вокруг объекта съемки занимал равномерный цвет. В качестве альтернативы фотобокса можно использовать 5 листов белого картона формата А4, склеенных между собой в форме куба, без одной стенки для выполнения съемки. Также можно использовать лист формата А1-А2 прикрепленный к жесткому вертикальному основанию одной из сторон. Размер фотобокса определяется относительно размера объекта съемки, с учетом его размеров и удобства использования. Пример альтернативы фотобоксу представлен на рисунке 4.

Для освещения объекта рекомендуется использовать классическую трехэлементную или двухэлементную систему, позволяющую максимально равномерно подсветить объект (рисунок 5). В качестве источников освещения можно использовать обычные настольные лампы или компактные светодиодные лампы/фонари.
