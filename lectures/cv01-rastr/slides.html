Без нейросетей. Ядро — линейный оператор на сетке.

Цифровое изображение

Функция I(x,y) на дискретной сетке. Пиксель — отсчёт, не «квадратик краски». Объектов нет, пока вы их не вычислили.

Сетка

Дискретизация

I[m,n] = (f ∗ Π)(m Δx, n Δy)Π — апертура пикселя; теорема отсчётов: мелкое < 2 px — алиасинг

Мегапиксели без ФПМ не спасают (А05/А06).

Свёртка

Каждый пиксель — взвешенная сумма соседей. Линейный фильтр. Ядро K размера (2k+1)×(2k+1).

Формула

(I ∗ K)[x,y] = Σi Σj I[x−i, y−j] K[i,j]

Сепарабельность: K = u vᵀ — два прохода 1D вместо одного 2D. Гаусс сепарабелен.

Собель

Градиент

|∇I| = √(Ix² + Iy²) · θ = atan2(Iy, Ix)

Модуль — сила границы. Угол — ориентация. Харрис и SIFT живут отсюда.

Гаусс и пирамида

Gσ = (1/(2πσ²)) e−(x²+y²)/(2σ²)

  • сгладить → проредить ×2 → следующий уровень
  • DoG ≈ LoG — блобы для SIFT
  • Крупное ядро без пирамиды — дорого и глупо

Квантование

N уровней = 2b8 бит → 256; 12 бит → 4096. K из А06 живёт здесь

Обрезка в 0 и 255 — дыры теней и клиппинг. Шум квантования ≈ шаг / √12.

Цвет как три массива

  • Байер: один фильтр на пиксель, демозаика — уже свёртка
  • Свёртка по каналам раздельно ≠ свёртка в Lab
  • NIR — четвёртый массив, его нет в JPEG телефона

Граничные условия ядра

  • zero / replicate / reflect / wrap
  • На АФС край кадра — и так хуже (виньетка, дисторсия)
  • Не сравнивайте ГРИП, обрезав 20 px без протокола

Связь с ФПМ

Свёртка с гауссом σ — умножение спектра на e−2π²σ²ν². Мелкое гасится. Шарп JPEG — обратное, плюс ореолы как ложные Харрисы.

Что сломает отождествление

  • Unsharp mask JPEG — ложные точки (качество кадра)
  • Сильный гаусс — убивает текстуру коррелятора
  • Медиана — края крыш «плывут»

Практика

  • Свой K на кадре ЦФК, кроп 100%
  • Гистограмма до/после — связь с K из А06
  • Не сдавать скрин фильтра телефона
