Изображение как массив

Первая пара CV: без нейросетей. Снимок — сетка чисел. Свёртка, градиент, пирамида. Мост: Ф04, гистограмма А06, серия ЦФК.

Определения

Цифровое изображение I[m,n] — отсчёты непрерывной яркости после апертуры пикселя и квантования. Теорема отсчётов: детали мельче ~2 пикселей дают алиасинг. «Больше мегапикселей» без ФПМ оптики не значит «точнее».

(I ∗ K)[x,y] = Σi,j I[x−i,y−j] K[i,j]

Гаусс сепарабелен: два 1D прохода. Собель — оценка производной. Модуль градиента — карта границ.

|∇I| = √(Ix² + Iy²)

Пирамида

Сгладить гауссом → взять каждый второй пиксель. DoG между уровнями ≈ лапласиан — детектор блобов для SIFT (CV02).

Практика

На своём JPEG/RAW серии ЦФК: своё ядро, кроп 100%, вывод «коррелятор потеряет / найдёт край». Шарп из камеры — враг отождествления.
