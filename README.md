# Курс АКС / АФС

Сайт лекций и практик МИИГАиК (Дрыга Д. О.). Статический HTML, без сборки.

Откройте `index.html` в браузере или включите GitHub Pages: Settings → Pages → Deploy from branch `main`, папка `/` (корень).

PDF из папки «Литература» в репозиторий не входят: ссылки работают с локального диска рядом с курсом.
